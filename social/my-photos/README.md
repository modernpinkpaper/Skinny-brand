# Your photos & clips go here

Film these on your phone: **upright (vertical)**, **5–10 seconds each**, natural light. Faces are optional, since from behind, hands or a mirror shot all work.
Short video clips are best: I use them as b-roll in the videos AND pull still photos from them for the carousels.
Photos (.jpg/.png) are fine too.

Name each file exactly like this (e.g. `crying.mp4`, `walk.jpg`):

| File name | What to film |
|---|---|
| `crying` | Upset on the bed or floor, head in hands / crying (for "I wish I knew…" hooks) |
| `stressed` | Stressed / rubbing temples / lying in bed awake at night |
| `phone` | Scrolling your phone on the couch or in bed |
| `laugh` | Laughing or a sassy look straight to camera (for roast hooks) |
| `mirror` | Happy outfit check in the mirror (jeans or a going-out outfit) |
| `mirror_meh` | Unimpressed / annoyed look in the mirror |
| `walk` | Walking outside, golden hour (from behind is perfect) |
| `coffee` | Holding / sipping an iced coffee or latte |
| `breakfast` | Making or eating eggs / Greek yogurt |
| `healthy_meal` | Eating a salad / healthy plate |
| `snack` | "Caught" eating chips or popcorn on the couch |
| `treat` | Eating a donut, pizza or dessert |
| `friends` | Girls' night, restaurant or drinks with friends |
| `kitchen_night` | Making tea, wiping the counter, switching the kitchen light off |
| `grocery` | Grocery store, picking up veggies |
| `workout` | Squats / dumbbells at home or the gym |

Then upload them to this folder on GitHub (open the folder → **Add file → Upload files**, then commit to the `claude/tiktok-digital-product-content-ihv4xr` branch), or send them to me in the chat.

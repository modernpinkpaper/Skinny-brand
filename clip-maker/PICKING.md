# How to go through the comments and pick script topics

(Adapted from my original instructions so it runs on its own: it never stops to ask me, and it never limits the number of topics.)

Study the comments broadly. Do not just pick one comment and rewrite it.
Look for repeated clusters of frustrations, emotions, questions, behaviors, problems, needs, or advice.
Group comments by the underlying experience, even when the commenters use completely different wording.

For each strong cluster, work out:
- what is happening on the surface
- what the deeper pain, problem or need may be
- whether the topic is mainly Emotional, Practical, or Educational
- which script formats from the script system fit it (every one that fits, the best one first)

Rules:
- Do not force every topic into a deep emotional meaning.
  - If the audience mainly needs a practical solution, it is Practical.
  - If the comments reveal an emotional pain point, it is Emotional.
  - If the comments ask for tips, explanations or strategies, it is Educational.
- A topic should be supported by several comments when possible. A single comment can carry a topic only when it is very strong, specific and clearly relatable.
- Keep topics specific, conversational, human, and based on patterns actually found in the comments.
- Find every strong topic. There is no limit. Do not stop to ask which ones to develop: every topic gets scripts.
- Skip jokes, spam, arguments, tags, and comments with nothing to build on.
